Pylon real-time model, RimWorld 1.7
Source: artifacts/pylon-refine/pylon_refined_v2.max (accepted 2026-10-29).
Exporter: artifacts/pylon-refine/export_game.py; input after_v2.json is a 3ds Max evaluated mesh snapshot.
Pylon.pmmesh: little-endian int32 version=1, object count; each object has int32 UTF-8 name byte count, name bytes, vertex count, index count; float32 xyz vertices and int32 triangle indices.
Coordinates: Max X/Z/-Y mapped to game local X/Y/Z, divided by 80; crystal centered at Max z=30; frame centered at y=43,z=24.55. No textures are required for runtime surfaces.
Runtime: Source/1.7/ProtossMech/CompPylonRingRailRenderer.cs.
Materials: Defs/ShaderDefs/PylonModel.xml and Shaders/PM17N_Pylon*.glsl.
Normal: translucent gold faceted core, three orbiting ivory-metal frames with UV-driven flowing gold honeycomb barriers.
Overcharge: elevated core; three cannons dash within 3 cells. Movement is shot-driven: each successful shot keeps its frame stationary for the 18-tick beam, then triggers one 18-tick dash followed by 12 settling ticks. Without a shot, no new firing point is chosen. Per-frame shot counts and timing survive save/load. Three cannons fire in sequence every 45 ticks (0.75 s) while a valid target is available. Original GraserBeam / MoteBeam material; one 20-damage beam per firing event; vanilla targeting, impact and armour calculations retained. Target retained while valid. 3000-tick overcharge duration and range 72 retained.
Outline: separate screen-space silhouette mask, 2.8 pixel radius with bilinear coverage; dedicated model-mask FXAA using the same screen-space orientation as the silhouette. Liquid grid and beam edge use derivative antialiasing.
The authoring material is not imported into the game. The native GLSL shaders supply surface colour and animation.

Frame linear size increased from 2.5 to 3.4 (36%). Crystal uses a separate transparent, non-depth-writing pass after metal and energy; no black hull behind transparent interiors.
